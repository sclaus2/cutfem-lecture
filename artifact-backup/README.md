# Backup of the lecture artifact

Snapshot of the Claude Slides artifact "Cut Finite Element Methods Lecture" (version around v316, 2026-11-19).

- `project/deck.json`: order and sections of the slides.
- `project/slides/<id>.html`: one HTML file per slide (1920x1080 canvas, speaker notes in `<aside>`).
- `assets/<id>.<ext>`: every image, GIF, video and SVG used by the slides. In the slides they are
  referenced as `/_blob/<id>`; the file name here is that id plus the extension.
- `SKILL.md`: the format description that comes with the Slides artifact type.

The figures and formulas are generated by the scripts in `../tools/` (run from the repository root with
`PYTHONPATH=.`). The artifact page itself (viewer and editor) is not part of this backup.
