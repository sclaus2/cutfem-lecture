Scan: repository

Two minutes, or skip it in the lecture and point to it. Everything we run in the lecture is minicut: one Python file with numpy, scipy and matplotlib, so it installs on Windows, Linux and macOS without a compiler. Before you start: Python 3.9 or newer from python.org (on Windows tick Add python.exe to PATH; on Linux install python3 and python3-venv, for example sudo apt install python3 python3-venv). Then the six lines, the same on every system except lines 3 and 4. Line 1 downloads the repository with git; without git open github.com/sclaus2/cutfem-lecture, click Code, Download ZIP, extract it, open the terminal in the extracted folder and skip lines 1 and 2. Line 3 creates a virtual environment named .venv, so that nothing is installed into the system Python, and line 4 activates it (Windows PowerShell: .venv\Scripts\Activate.ps1; Linux and macOS: source .venv/bin/activate). Line 5 installs what the file requirements.txt in the repository folder lists: numpy, scipy, matplotlib and jupyterlab. Line 6 starts JupyterLab with the notebook, and it opens in the browser. Next time only line 4 and line 6 are needed. To get only minicut without the notebook, create and activate the environment (lines 3 and 4) and run pip install https://github.com/sclaus2/cutfem-lecture/archive/main.zip; import minicut then works in any folder. If PowerShell blocks the activation script, Set-ExecutionPolicy -Scope Process Bypass allows it for this window only. The notebook finds minicut.py in the folder above it, so keep the folder structure. Not tested here: Google Colab or other online notebooks.
